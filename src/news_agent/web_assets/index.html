ABOUT THIS WORKSPACE

读懂每一次调查

输入问题后，由项目 Agent 自己搜索和选择网页。调查图谱展示真实工具动作；新版运行可公开发布计划、缺口及补证理由。

旧记录没有这些公开计划时，只展示已有动作，不补造模型的想法。“时间回溯”指调查更早的事件证据；运行回放仅用于查看过去动作，不会再次调用 API。

新版时间线与报告共用已保存的事件发现，未知日期单列；旧流程使用其历史记录。点击引用可对照保存的原文。来源相互独立、内容真实、日期准确仍需判断。

停止或预算不足会保留 partial 报告。离线样例使用合成事件与脚本模拟模型，不回答你输入的真实问题。
